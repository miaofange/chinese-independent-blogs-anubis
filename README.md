# 中文独立博客 · Anubis / uBlacklist 列表

[timqian/chinese-independent-blogs](https://github.com/timqian/chinese-independent-blogs) 的搜索过滤格式转换，GitHub Actions 每日自动同步。收录错漏请到源仓库提 issue/PR，这里不维护条目。

## 订阅

- **Anubis**：[一键订阅](https://bishop-v.github.io/anubis/subscribe?url=https%3A%2F%2Fraw.githubusercontent.com%2Fmiaofange%2Fchinese-independent-blogs-anubis%2Fmain%2Fout%2Fchinese-independent-blogs.anubis&name=%E4%B8%AD%E6%96%87%E7%8B%AC%E7%AB%8B%E5%8D%9A%E5%AE%A2)，或把 [列表地址](https://raw.githubusercontent.com/miaofange/chinese-independent-blogs-anubis/main/out/chinese-independent-blogs.anubis) 粘贴到 设置 → 列表 → 添加列表
- **uBlacklist**：订阅 [chinese-independent-blogs.txt](https://raw.githubusercontent.com/miaofange/chinese-independent-blogs-anubis/main/out/chinese-independent-blogs.txt)（高亮规则）

Anubis 中默认只显示「独立博客」标签，不动排名；效果（高亮 / 提升 / 置顶 / 隐藏）在 **设置 → 标签** 里自选。
